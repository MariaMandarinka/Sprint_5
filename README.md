# Проект автоматизации тестирования сервиса Stellar Burgers

Репозиторий содержит UI-автотесты для веб-интерфейса бургерной Stellar Burgers. Тесты написаны в рамках обучения на курсе «Автоматизатор тестирования».

## Стек технологий
* **Язык программирования:** Python 3
* **Фреймворк:** Pytest (версия 9.x)
* **Инструмент автоматизации:** Selenium WebDriver 4

## Архитектура проекта
Проект организован по правилам чистого кода и современным стандартам pytest:
* `tests/` — основная директория с тестами.
* `tests/conftest.py` — конфигурационный файл, содержащий общие фикстуры для управления браузером и генераторы уникальных тестовых данных (логинов и паролей) под каждую сессию.
* `tests/locators.py` — изолированное хранилище XPATH-локаторов элементов интерфейса (Page Object подход) с подробными комментариями.
* `tests/test_registration.py` — автотесты для формы регистрации пользователей.
* `tests/test_login.py` — автотесты для проверки различных точек входа в систему.

## Инструкция по запуску тестов

1. Убедитесь, что у вас установлены зависимости (Selenium и Pytest).
2. Запустите все тесты из корневой директории проекта одной командой:
   ```bash
   pytest tests/ -v
.   ```
